### Travailler en Local
```bash
# Backend
cd backend
source venv/bin/activate
uvicorn app.main:app --reload

# Frontend
cd frontend
npm run dev
```

### Créer une branche
```bash
git checkout -b feature/nouvelle-fonctionnalite
# Faire vos modifications
git add .
```
